\begin{abstract}
Fresh randomness does not necessarily produce fresh information in an adversary's observations. We demonstrate this distinction in \scheme{}, an NDSS 2026 defense that combines secret linear transformations, additive markers, and independently shuffled KV-cache blocks. A repeated-token text prompt makes the first-layer Value rows identical. Shuffling then changes only the marker's position: the protected blocks occupy an orbit of at most $b$ states, despite $b!$ possible permutations. Differences between these states reveal a rank-one structure from which an adversary can recover an equivalent row demixer and the implementation's structured column transform. The recovered parameters transfer to other requests protected by the same secrets; the attacker obtains token multisets without recovering within-block order. We characterize the orbit, state the nondegeneracy conditions for identification, and derive a query bound. Against the official implementation, the attack recovers 263,029 of 263,904 head--token evaluation instances across ten models and twelve configurations. Fifteen additional model--key epochs all calibrate successfully, with model-level mean recovery between 99.34\% and 100\%. A limited, single-key study of 30 synthetic closed-set values yields 77.36\% expected top-1 identification under uniform tie-breaking; we explicitly distinguish this observation from population-level privacy estimates. Request-specific refresh of the row transform and marker blocks the tested cross-request transfer, without establishing a complete secure repair. The results identify a concrete failure mode: input symmetry can neutralize fresh shuffling while exposing reused secrets through its remaining marker orbit.
\end{abstract}
